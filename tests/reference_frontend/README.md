# Frozen frontend baseline

These private helpers preserve the 0.7.0a2 implementation for historical contract
and compatibility comparisons. They are test fixtures, excluded from the explicit
`rofi_tmux_plus` wheel package and native release bundle. They must never be imported
by product code. Pure/support aliases retain the same exception/type identity.

Observer's independent tests and installed gates own the extracted native,
networking, desktop and action behavior. Passing this baseline's tests does not
accept the replacement implementation. Active consumer/import/C5 tests, public
CLI fixtures, installed direct/action checks and endpoint-specific Rofi acceptance are
separate gates. The old first-title focus behavior is deliberately superseded by
fresh unique matching; its historical tests remain baseline evidence only.

Historical spawn/lock/cooldown tests explicitly supply fixture argv to their
mocked process starters. They do not require or execute an operator-installed
launcher. Resolution/failure tests continue to exercise the actual resolver.
