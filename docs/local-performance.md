# Attachment-driven local display candidate

Tmux Plus 0.9.0a1 consumes the additive `bindings-v1` producer contract. A local
match is retained for a current native client incarnation and displays as
`open here?`. Its discovery time does not advance with native receipts. Remote
C3 capture expiry, local native-binding expiry, and native Attached membership
remain independent. The UI supplies no window/process/action handles; actions
continue to resolve and validate their current targets independently.

The candidate pin is Observer 0.3.0a1 runtime
`5a4aec9c7f4208d47dd35816c1350a61538d0076`, wheel SHA256
`e98051a8f93373790082df8aeae462c63498b2bc9c7454eca62aec146c5b6945`.
It checks all 77 producer Python modules in three package roots. The existing
six contract bundles and nineteen action modules are unchanged. The producer
passes its 356-test source gate, independent repeated artifact builds, local
native binding/attachment/recovery/action and installed capacity checks.
Ordinary two-host resource acceptance remains a separate gate.

The consumer source gate passes 293 tests. Pure-contract integration rejects a
foreign publisher; consumer regressions cover qualified membership without C3,
per-host expiry, watch/context loss, unchanged discovery time and quiet renewal.
The native picker harness adds actual Kitty retention across lease renewal and
detach-driven Open removal. Those graphical and paired artifact gates must pass
before publication/selection. Source acceptance is not managed deployment.

Kitty tab/internal-window relocation without a native client change is an
accepted limitation. Explicit Refresh requests rediscovery. Unknown/ambiguous
clients remain unknown after three bounded settling attempts. The authoritative
implementation and failed/superseded evidence ledger is Observer's
[local performance implementation](https://github.com/byebyebryan/tmux-observer/blob/main/docs/local-performance-implementation.md).
