# Tmux Plus 0.9.0a1 retained local Open

The picker consumes Observer's additive retained local binding contract. Stable
Kitty clients keep a qualified `open here?` association while their native
attachment lease is current; receipt renewal never changes discovery time or
claims a new desktop capture. Local native-binding expiry and remote C3 capture
expiry remain independent. Context/watch loss revoke retained positives. Native
Attached remains independent, and actions resolve/revalidate their current
targets without a retained window handle. Kitty tab/internal-window relocation
without a native client change remains an accepted limitation.

`4408baee5fb4506aa32e19aaf874ca71d6ace8ac7aa4b526cbdb330b2cf960e9`.
Its exact Observer 0.3.0a1 pin is runtime `5a4aec9`, wheel
`e98051a8f93373790082df8aeae462c63498b2bc9c7454eca62aec146c5b6945`,
with all 77 Python module hashes. Existing action modules and six contracts are
unchanged. [Producer native/resource acceptance](https://github.com/byebyebryan/tmux-observer/blob/main/docs/tmux-observer-0.3.0a1.md)
is independent of this consumer's source/GUI acceptance.

The full source gate passes 293 tests, including pure-contract integration,
