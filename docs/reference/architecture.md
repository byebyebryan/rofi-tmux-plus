# Tmux Plus client boundaries

Plus owns presentation and explicit intent. Tmux Observer owns native facts,
prepared fleet/desktop composition and separate action validation. Mesh owns
configured host authority and cached transport. Agent Plus native entry remains
independent of all Tmux runtime paths.

## Prepared browsing

The picker reads an already running local prepared Fleet v1 view and its watch.
Startup and browsing perform no native tmux, SSH or desktop collection and start
no upstream service. A missing or incompatible reader is an explicit failure;
there is no direct fallback.

Keep complete native references and the independent owner/viewer/association
receipts. Open means current endpoint-local viewer evidence; Attached means
positive native tmux attachment evidence, potentially from another desktop.
Qualified `open here?` display evidence grants no verified close handle.
Unknown membership and unavailable/expired facts remain explicit.

## Explicit operations

Alt+R uses Observer's separate bounded passive refresh path. Public inventory is
an explicit fresh operation. Lifecycle/window actions independently validate
current route, complete native reference and required desktop binding.
Cached presence, a label or prior successful focus is no action authority.

Open chooses focus/attach through the guarded action client. Kill requires a
frozen exact target and explicit confirmation starting on Cancel. Native agent
conversation control remains with native provider managers.

## Compatibility and acceptance

The exact Observer artifact guard covers its version and complete module bytes;
see [development](../maintenance/development.md). The public [Tmux Session v1](tmux-session-v1.md)
facade remains distinct from cached prepared reads. [Mesh integration](../guides/mesh-integration.md)
links producer configuration, selections and recovery ownership.

Source, installed native, headless callback, graphical/input and physical proofs
are separate. The [Observer runtime architecture](https://github.com/byebyebryan/tmux-observer/blob/main/docs/reference/architecture.md)
defines current component responsibilities.
